# 260 号工作流：短信验证码、连续扫码与候选栏快捷操作

基线：`feature/workflow259-voice-color-followup-backup-restore`

本分支：`feature/workflow260-sms-barcode-smart-actions`

## 已确认的交互约定

### 短信验证码
- 用户主动开启后才申请并使用 `RECEIVE_SMS` 权限；关闭开关后停止处理。
- 仅在本机解析短信正文，提取上下文明确的 4、5、6 位验证码；不上传短信内容。
- 候选栏展示验证码，点选上屏；提供复制入口。
- 避免把电话号码、订单号、金额等普通数字误当验证码。

### 二维码 / 条形码
- 从「常用功能」和自定义手势均可启动。
- 摄像头预览持续运行，识别到一个码后不自动退出、不停止预览。
- 每次识别成功立即复制结果到系统剪贴板并提示；同一画面持续识别时做短时去重，镜头移开后再次扫到同一内容仍可再次复制。
- 扫描框可拖动并调整大小；用户主动关闭扫描页才结束扫描。
- 仅在扫描页前台运行时使用摄像头，退出立即释放相机。

### 候选栏快捷操作
- 「电话」「短信」触发对应系统应用。
- 识别到手机号时提供拨号与发短信两个明确入口，不直接自动拨号。
- 不覆盖正常文字候选的点击行为。

## 验收重点
- 短信权限拒绝 / 关闭开关时不崩溃、不监听；重新授权后可恢复。
- 4/5/6 位验证码正确提取，普通数字误报受控。
- 连续扫描多个不同二维码和条形码，扫描页始终保持打开，结果逐次复制。
- 扫描框拖动、缩放后仍可准确识别。
- 电话、短信和手机号候选动作可用；其它文字候选不受影响。
